
Projeto da disciplina Desenvolvimento Web II — Fatec Porto Ferreira.

Responsável: Henry Sena Oliveira

O objetivo é uma aplicação web para divulgar eventos acadêmicos, permitir cadastro de usuários, inscrições e gerenciamento de eventos por organizadores e administradores.

Tecnologias usadas: Python 3.11+, Flask, Flask-SQLAlchemy, SQLite/PostgreSQL, HTML, CSS, JavaScript Fetch API, Git e GitHub.
